# Deepseek Harness 项目详细计划（Week / Day 拆分）

目标：在 3 天内理解、运行并扩展一个 Deepseek Harness 示例，实现并测试一个简单插件/数据源适配器。

总体时间预算：3 天，每天 3-4 小时（可根据实际情况延长）。

Day 1 — 理解与运行（3-4 小时）
- 目标：能在本地启动 harness 并运行示例流程。
- 任务：
  1. 阅读 README、快速浏览代码结构（30-45 分钟）
  2. 安装依赖（pip / npm / go mod），解决环境问题（30-60 分钟）
  3. 按仓库说明运行示例服务或客户端（30 分钟）
  4. 使用自带示例插件触发一次完整的工具调用/流程（30 分钟）
  5. 记录关键日志与遇到的问题（30 分钟）
- 验收：本地能启动服务并看到插件执行或 UI/CLI 返回结果。

Day 2 — 插件/适配器开发（3-4 小时）
- 目标：实现并加载一个自定义插件/数据源适配器。
- 任务：
  1. 根据 Day1 的调研，确定插件接口（15-30 分钟）
  2. 编写插件代码（2 小时）
  3. 添加单元测试（30-45 分钟）
  4. 在本地 harness 中加载并验证插件（30 分钟）
  5. 修复运行时错误并记录边界条件（30 分钟）
- 验收：插件能在 harness 中被加载并返回预期结果；测试通过。

Day 3 — 安全、集成与文档（3-4 小时）
- 目标：配置基本沙箱/权限、集成外部 API（可选），完成文档与 demo。
- 任务：
  1. 阅读并理解 harness 的权限/沙箱机制（30 分钟）
  2. 限制插件权限并验证不可越权操作（30-60 分钟）
  3. （可选）集成外部 API（例如 Web 搜索或简单 LLM）增强插件能力（60-90 分钟）
  4. 编写 1 页技术总结（运行步骤、架构要点、改进建议）并准备 demo 脚本（30-45 分钟）
- 验收：权限配置生效，文档齐备，并能运行 demo 展示插件功能。

拓展任务（可选）：
- 将插件打包并提交到目标仓库的插件市场或 PR。
- 性能评估：测量延迟、并发处理能力并提出优化方案。

交付物：
- code/ 下的插件实现与测试
- notes/ 下的学习笔记与复盘
- results/ 下的样例输出与 metrics
- 一个 1 页的技术总结（README/insights.md）
